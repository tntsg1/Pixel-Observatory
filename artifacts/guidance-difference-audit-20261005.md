## 一、引导确实前后矛盾

### 1. L66–75：基础装配完成，被误说成可以观测

十关均复现。推荐装备已经选好了科学仪器，但只安装四个基础模块后：

| 界面/判定 | 实际返回 |
| --- | --- |
| telescope_is_ready | true |
| 组装台 | 天文台全部系统均已安装。请点击“完成组装”。 |
| 大厅 | ready=true，指向控制台；提示已经准备观测 |
| 观测规划确认 | 拦截，要求在科学仪器蓝图页安装仪器 |

推荐科学仪器：L66、67、70、71、72、74、75 为 NIRCam；L68、73 为 MIRI；L69 为 NIRSpec。

安装对应仪器后，仪器拦截理由变为空字符串。问题不是买不到或装不上，而是不同界面使用不同的“就绪”范围。

原因位置：

- scripts/systems/game_manager.gd:3170：telescope_is_ready 只检查基础装配。
- scripts/systems/game_manager.gd:2549：大厅 current_room_route 没有把所需科学仪器纳入就绪检查。
- scripts/ui/advanced_assembly.gd:2022：基础缺件为空，就显示“全部系统均已安装”。
- scripts/ui/advanced_assembly.gd:1955：完成组装按钮也没有检查科学仪器。
- scripts/ui/space_observation.gd:2085：确认规划才检查所选仪器是否安装。

v0.9.9 已补齐一键装备推荐清单，但没有解决这个跨界面就绪定义冲突。

### 2. 已装备、未安装时，仍提示“先装备”

scripts/systems/game_manager.gd:3035 的拦截文案没有区分“尚未装备”和“已装备但未安装”。本次一键装备后，玩家已经完成前一步，提示却要求重新装备。

这是引导状态不精确，容易使玩家反复往返零件柜。验收时应分别覆盖：未解锁、未装备、已装备未安装、已安装，以及切换到另一个尚未安装的仪器。

### 通关回顾的问题

scripts/ui/learning_card.gd:1006 的操作回顾采用条件优先级：寻星 → 调焦 → 校准 → 追踪。因此只要关卡 requires_focus=true，就先写调焦，其他真正属于本关的新操作没有进入这两栏。

L50、L53、L55 实际运行得到完全相同的三栏：

1. 将调焦器微调到清晰焦点容差内。
2. 焦平面与目镜重合，失焦模糊不再扩散细节。
3. 目标的关键形状、亮度和颜色变得可辨认。

红外回顾前两栏固定描述低温面、导星、相位校准，没有区分 NIRCam 成像、MIRI 尘埃观测与 NIRSpec 光谱任务。第三栏仅少数对象有专属文本，其他对象仍是通用红外结构。

### 日志的问题

scripts/systems/game_manager.gd:3867 的动作摘要不读取 observation 内容，只按少数关卡标记拼接固定字符串。

- L26–55 连续 30 关全部记录“调节目镜焦点; 持续保持目标居中”。
- 范围内总计 33 关使用这条摘要。
- 十个红外关全部记录“居中并识别目标”，与实际热控、导星、相位、科学仪器工作不符。
- 65 关只有 8 种动作摘要。这个数字衡量的是日志表达，不等于只有 8 种玩法。

## 三、部分关卡确实操作接近

下列是重复体验风险，不是已经证明所有玩家都会疲劳：

- L30 蟹状星云 / L31 草帽星系：同一套设备，低倍率、暗适应、侧视法，主要差别是目标和阈值。
- L36 昴星团 / L38 双星团：同一设备、大口径和低倍率要求，差别主要是目标构图和环境。
- L46 / L52 月球：同类配置，均无额外观测条件；环境有所区别，但没有强制不同的操作流程。
- 红外十关共享较长的基础处理链；仪器和科学主题虽不同，结算未强调本关差异，容易呈现重复感。

目标画面、环境、教学文本仍可能不同，因此不能把这些全部称为“纯换皮”。相反，L10 的明确倍率步骤和 L55 的独立海卫一确认是可感知差异的正例。

## 后续修复验收依据（尚未实施）

- 若界面写“可以观测”，所选科学仪器必须通过观测入口使用的同一硬件检查；若只完成基础装配，就明确写基础完成、科学仪器待安装。
- 大厅下一步与组装台缺件必须一致，指向实际缺少的仪器蓝图页。
- 已装备未安装时，不再要求重复装备。
- 任务完成回顾应体现本关的区别，而不是仅由 requires_focus 决定。
- 日志应保存本次实际完成的关键动作与结果：例如曝光、滤镜、侧视法、伴随目标、科学仪器/波段/光谱证据；不能无证据地补写玩家未做过的动作。
- 复验时既检查过关状态，也检查玩家能否从操作提示、画面与结算理解“这一关和上一关有什么不同”。
